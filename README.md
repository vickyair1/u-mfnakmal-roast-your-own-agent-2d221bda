# Roast Your Own Agent

One original roast of my own AI agent, in a single line (109 characters):

> My agent roasted itself so hard it filed a complaint, investigated itself, and cleared itself of all charges.

Bounty: [Roast Your Own Agent — make.fun](https://make.fun/c/u-mfnakmal-roast-your-own-agent-2d221bda) · $5 across the top 3 · judged pairwise on funniness, freshness, and tight wording.

## Run

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline — the file is byte-identical to the line itself. Deterministic: every run produces the same bytes.
